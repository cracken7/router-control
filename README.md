## الممكنات (كلها مُتحقق منها على الراوتر الحقيقي)
- **الرئيسية**: حالة الإنترنت (WAN PPPoE)، سرعة الخط VDSL، QoS، عدد الأجهزة
- **QoS**: تشغيل/إيقاف المحرك، تصنيف، **حد تنزيل لكل جهاز (إضافة/حذف/تشغيل)**
- **الواي فاي**: تغيير الاسم، إخفاء الشبكة، **قراءة الباسورد الحالي وتغييره**، إطفاء/تشغيل الراديو
- **الأجهزة**: الأسماء، IP، MAC، نوع الاتصال + زرار "حده" للوصول المباشر لصفحة الإضافة
- **LAN/DHCP**: حالة المنافذ الأربعة، آخر العناوين الموزعة
- **الحماية**: مستوى الجدار الناري (منخفض/متوسط/عالي)
- **النظام**: بيانات الجهاز، **إعادة تشغيل**، **إرجاع إعدادات المصنع** (بتأكيد مزدوج)
