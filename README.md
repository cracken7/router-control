# Router Control — ZTE ZXHN H168N V3.5

لوحة تحكم محلية لراوتر ZTE ZXHN H168N V3.5 (فيرموير `V3.5.0_EG1T13_ET` — WE/اتصالات مصر)
مبنية على بروتوكول مستخرج من الفيرموير نفسه ومُتحقق منه **على الراوتر الحقيقي**.

## التشغيل
```
cd C:\Users\Admin\router-agent\app
python server.py
```
ثم افتح: **http://127.0.0.1:8766**

## الممكنات (كلها على الراوتر الحقيقي)
- **لوحة رئيسية**: حالة QoS، عدد الأجهزة، حد التنزيل، وقت الراوتر
- **QoS Global**: تشغيل/إيقاف المحرك (كتابة مُتحقق منها)
- **Classification**: قراءة قواعد التصنيف
- **Congestion Management / Traffic Shaping**: قراءة (فاضيين على الجهاز الحالي)
- **Traffic Policing**: قراءة فقط — البوليسرز مقفولة من فيرموير التيليكو نفسه
- **Downside speed limit**: تشغيل/إيقاف الحد العام + قواعد لكل جهاز (كتابة مُتحقق منها)
- **الأجهزة المتصلة**: أسماء، IP، MAC، نوع الاتصال (واي فاي/كابل)
